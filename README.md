# "Memory Game" (Игра в пары)

Интерактивная игра на развитие памяти, созданная на чистом JavaScript  в рамках учебного задания RS School.

## 📝 Описание проекта
Игра на поиск пар: игрок открывает карточки и запоминает их расположение, чтобы найти все совпадения за наименьшее число ходов.

### 🚀 Выполненные технические требования (ТЗ):
* **Абсолютно пустой тег `<body>` в HTML:** Вся разметки приложения (контейнеры, кнопки, счетчики, сетка карточек и модальные окна) создается динамически через JavaScript с помощью `document.createElement`.
* **Безопасная работа с DOM:** В коде полностью отсутствуют запрещенные методы `innerHTML`, `outerHTML` и `insertAdjacentHTML`.
* **Кнопка "New Game":** Сбрасывает игровое поле и счетчики ходов без перезагрузки всей страницы, а также мгновенно отменяет активные таймеры переворота несовпавших карт.
* **Переиспользуемый компонент модальных окон:** Окна победы и таблицы лидеров работают через единую универсальную функцию-оболочку, предотвращая дублирование кода.
* **Универсальные способы закрытия окон:** Модальные окна закрываются кнопкой "Close", кликом по затемненному фону вокруг окна или клавишей `Escape` на клавиатуре. При открытии окон прокрутка страницы блокируется, а при закрытии — восстанавливается.
* **Таблица лидеров (Leaderboard):**
  * Данные сохраняются локально в памяти браузера (`localStorage`).
  * Отображаются топ-10 лучших результатов с указанием места, числа ходов и даты в формате `ДД.ММ.ГГГГ`.
  * Реализована сложная сортировка: при равенстве ходов выше отображается более ранняя игра.
  * Если рекордов еще нет, выводится сообщение *"No scores yet"*.
